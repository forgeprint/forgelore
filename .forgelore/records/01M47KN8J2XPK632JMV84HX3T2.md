Any later run of ci.sh calls crosscheck.sh, which rewrites dist/ in place with a git-describe stamp and leaves SHA256SUMS describing bytes that are gone. Pack npm from a freshly downloaded release, not from whatever dist/ happens to hold. npm-pack.sh now refuses the mismatch.
